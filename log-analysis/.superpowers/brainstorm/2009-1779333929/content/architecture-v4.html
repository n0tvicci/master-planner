S3 output path convention:
logs/{ninja_device_id}/{incident_id}/{script_name}/output.txt Lambda generates pre-signed PUT URL for this path before firing the script. Script receives URL as parameter and uploads directly. Lambda knows exactly where to read — no guessing.
Job status polling:
Lambda polls NinjaOne job status after firing script. On SUCCESS → reads S3. On FAILED → returns error to Agent so it can reason about the failure. Polling timeout = ~5 min with exponential backoff.
