# Automated Faceless YouTube Shorts Channel Strategy

### Military & Historical Weapons Niche | Tier 1 Audience Targeting | Full Compliance

---

## Overview

Build a fully automated faceless YouTube Shorts channel in the military and historical weapons niche, modeled after channels like ArmorXpress (@armorxpress), with a deliberate strategy to attract and retain Tier 1 audiences — primarily the United States, United Kingdom, Canada, and Australia — to maximize CPM and ad revenue, while being fully compliant with YouTube's monetization, content, and AI disclosure policies.

The content style is specifically: short educational myth-busting videos that reveal the surprising truth behind common assumptions about military equipment, weapons, tactics, and historical warrior tools. All videos are fully faceless. Visuals are simple close-up demo footage of the object being discussed, or short animations explaining how a mechanism works, sourced from royalty-free stock footage or AI-generated video.

### Title Formulas

- `Why do real [soldiers/snipers/pilots] actually [surprising behavior]?`
- `Why did [historical group] use [object] to [action]?`
- `Why [common assumption about military topic] is completely wrong?`
- `Why modern [weapon/equipment] no longer [expected feature]?`

### Confirmed Viral Short Structure

| Timestamp | Section     | Purpose                                       |
| --------- | ----------- | --------------------------------------------- |
| 0–3 sec   | Hook        | State the common assumption or paradox        |
| 3–10 sec  | Validation  | Why most people believe the wrong thing       |
| 10–35 sec | Truth       | Historical origin or technical reality        |
| 35–50 sec | Final Twist | A detail MORE surprising than the main answer |

> **Rule:** No CTA, no fluff, no filler. End on the twist. Always.

### Content Tone

Conversational, confident, slightly conspiratorial — like a knowledgeable friend sharing a secret, not a lecturer.

### Minimum Originality Standard

Every script must:

- Reveal at least one non-obvious fact not learnable from watching the footage
- Correct a specific named common misconception
- End with a detail more surprising than the main answer

## 3. Content Sourcing & Footage Strategy

### Core Visual Strategy

Show the object being discussed while the narration reveals the surprising truth about it. Footage does not need to be dramatic — it just needs to clearly show the weapon, equipment, or mechanism being discussed.

### Primary Stock Footage Sources

| Source            | Type                | Cost | API Available |
| ----------------- | ------------------- | ---- | ------------- |
| Pexels            | Royalty-free video  | Free | Yes           |
| Pixabay           | Royalty-free video  | Free | Yes           |
| Wikimedia Commons | Public domain       | Free | Yes           |
| Internet Archive  | Historical military | Free | Yes           |

### AI Video Generation (When No Stock Exists)

Use when the script describes an internal mechanism or historical object with no available footage.

| Tool      | Best Use Case                    |
| --------- | -------------------------------- |
| Kling AI  | Photorealistic weapon close-ups  |
| Runway ML | Mechanism animations             |
| Pika Labs | Short object demonstration clips |

### Per-Clip Clearance Checklist

- [ ] License type confirmed as commercial-safe
- [ ] No background copyrighted audio
- [ ] No third-party watermarks visible
- [ ] No news broadcast elements
- [ ] Background audio stripped before assembly

### Footage Never Acceptable

- Graphic combat casualties or gore
- Explicit violence or injury
- Copyrighted news broadcast clips
- Clips with visible third-party watermarks
- Footage from active ongoing conflicts

### Footage Logging System

For every clip used, record:

- Source URL
- License type
- Clearance status
- Date accessed
- Video it was used in

## 4. Automation Pipeline Architecture

```
Step 1:  Topic Generation      → Claude API generates 10 topic ideas with titles
Step 2:  Topic Selection       → Automated scoring or human pick
Step 3:  Script Generation     → Claude API full script + all scores
Step 4:  Script Compliance Gate → Auto-reject if any score below minimum
Step 5:  Voiceover Generation  → ElevenLabs API
Step 6:  Footage Search        → Pexels API + Pixabay API per sentence
Step 7:  Footage Clearance     → License check + mandatory audio strip
Step 8:  AI Video Generation   → Kling/Runway for footage gaps
Step 9:  Asset Delivery        → All assets packaged for editor
Step 10: Video Assembly        → Manual: CapCut or DaVinci Resolve (~15 min)
Step 11: Pre-Upload Gate       → Full compliance checklist must pass
Step 12: Metadata Generation   → Claude API: title, description, tags
Step 13: YouTube Upload        → YouTube Data API v3
Step 14: Post-Upload Monitor   → Copyright check 24hr, monetization check 48hr
```

### Mandatory Human Review Checkpoints

- Script compliance gate (Step 4): review if REVISION REQUIRED is flagged
- Asset review (Step 9): confirm all clips are correct before editing
- Pre-upload gate (Step 11): final human sign-off before publishing

## 8. Voiceover & Accent Strategy for Tier 1

### ElevenLabs Recommended Settings

| Parameter        | Value                                   |
| ---------------- | --------------------------------------- |
| Voice Style      | American male, confident, authoritative |
| Stability        | 0.65–0.75                               |
| Similarity Boost | 0.80–0.85                               |
| Style            | 0.30–0.45                               |
| Speaker Boost    | Enabled                                 |
| Export Format    | MP3, 44.1kHz, 192kbps                   |

### Voiceover Pacing Rules

- 140–150 words per minute
- Slight pause after the hook sentence
- Emphasis on the key twist reveal word
- No robotic rhythm — vary sentence length in the script to force natural pacing

### A/B Voice Testing Framework

- Test 2 different American voices across 10 videos each
- Measure: US audience share %, average view duration, comment sentiment
- Keep the voice with higher US audience share after 20 video sample

## 10. Video Assembly (CapCut / DaVinci Resolve)

### Overview

Video editing for this channel is intentionally simple. The script, voiceover, and footage do all the work. Assembly is purely organizational — under 15 minutes per video once all assets are ready.

### Asset Checklist Before Opening Editor

- [ ] All footage clips downloaded and background audio stripped
- [ ] Voiceover MP3 from ElevenLabs ready
- [ ] Background music track (royalty-free) ready
- [ ] Script open for text overlay reference
- [ ] Keyword overlay list from script output ready

### CapCut Assembly Steps

| Step | Action                                                                                | Time  |
| ---- | ------------------------------------------------------------------------------------- | ----- |
| 1    | New project, canvas 9:16 (1080x1920)                                                  | 1 min |
| 2    | Import and arrange clips in script order, hard cuts only                              | 5 min |
| 3    | Drop voiceover MP3, align to start of timeline                                        | 1 min |
| 4    | Drop background music, set volume to 12–15%, fade out last 3 seconds                  | 1 min |
| 5    | Add keyword text overlays per sentence — ALL CAPS, white, black outline, center frame | 4 min |
| 6    | Auto Caption from voiceover track, style: white text black pill, upper third          | 2 min |
| 7    | Export: 1080x1920, MP4, 30fps, High Quality                                           | 1 min |

**Total: ~15 minutes per video**

### Text Overlay Style Specification

- Font: Heavy or Black weight
- Color: White fill, black outline
- Position: Vertical center, horizontal center
- Case: ALL CAPS
- Length: 1–3 words maximum

### Pre-Export Quality Checklist

- [ ] Voiceover clearly audible above music at all times
- [ ] No clip longer than 5 seconds without a cut
- [ ] Keyword text synced with spoken word
- [ ] Captions accurate and readable
- [ ] First frame is not black — video starts immediately
- [ ] Total length 45–58 seconds
- [ ] No copyrighted audio audible in any clip background
