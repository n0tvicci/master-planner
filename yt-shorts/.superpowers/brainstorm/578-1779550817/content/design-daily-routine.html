Design Section 2: Daily Routine

Your full working day from cold start to published video. Total active time: ~35–45 minutes.

Daily Workflow — On-Demand (run whenever you're ready)
ONCE/WEEK
Top up the topic queue

Run python pipeline.py --topics-only → Claude generates 20 topics, appends to topics/queue.json. Open the file, find topics you like, set their status to "approved". Takes ~5 min. You'll always have a week's worth of approved topics ready.

STEP 1
~1 min
Run the pre-edit pipeline

python pipeline.py

Picks the first approved topic from queue, generates script, checks compliance, creates voiceover, searches and downloads footage, strips audio, detects gaps. Runs fully unattended once started.

WAIT
~5–8 min
Pipeline runs automatically

Go make coffee. The script prints progress to terminal. You'll see a final asset summary when it's done.

STEP 2
0–5 min
Fill Runway gaps (if any)

Check assets/<job-id>/footage-gaps.md. If the file is empty — skip this step entirely. If gaps exist, open Runway ML, paste each pre-written prompt, download the clip, drop it in footage/<job-id>/gaps/, then re-run python pipeline.py to finalize packaging.

STEP 3
~15 min
Edit in CapCut

Open assets/<job-id>/ — all clips are numbered, audio-stripped, and ready. Voiceover and script are in the same folder. Follow the 7-step CapCut assembly from your instruction.md. Export to output/<job-id>/.

STEP 4
~2 min
Run the publish pipeline

python publish.py --job <job-id>

Runs pre-upload gate, generates metadata (title, description, tags, pinned comment), uploads to YouTube with AI disclosure enabled. Prints a monitoring card with 24h / 48h / 72h checkpoints.

DONE
Video is live

Check back in 24h for copyright status, 48h for monetization, 72h for country distribution. The monitoring card tells you exactly what to look for.

Time breakdown

  • Pipeline run: ~5–8 min (unattended)
  • Runway gaps: 0–5 min (usually 0)
  • CapCut editing: ~15 min
  • Publish run: ~2 min
  • Total active time: 17–25 min

Skip days are zero-guilt

Because you run on-demand, a missed day is just a missed day — no scheduled jobs fail, no queues back up. The approved topic queue means you're never blocked by a "what do I make today" decision.
