Design Section 3: File Structure & Tool Scripts

Every file that will exist in this project and what it does.

Orchestrators (you run these)

pipeline.pyPre-edit orchestrator. Flags: --topics-only (generate queue only), --job <id> (resume specific job)
publish.pyPost-edit orchestrator. Flags: --job <id> (required), --dry-run (preview metadata without uploading)

Tool Scripts (tools/)

ScriptAPI UsedInput → Output
generate_topics.pyClaude APInone → appends 20 topics to topics/queue.json
generate_script.pyClaude APItopic → scripts/<job-id>/script.json (script + scores + footage queries)
check_compliance.pynonescript.json → PASS or halts with revision instructions
generate_voiceover.pyElevenLabs APIscript text → voiceover/<job-id>/voiceover.mp3
search_footage.pyPexels + Pixabayfootage queries → downloads clips to footage/<job-id>/ (concurrent per sentence)
clear_footage.pyffmpeg (local)raw clips → audio-stripped clips + compliance-logs/<job-id>/clearance.json
check_footage_gaps.pynoneclips + script → assets/<job-id>/footage-gaps.md (Runway ML prompts)
package_assets.pynoneall job outputs → numbered asset bundle in assets/<job-id>/ + edit checklist printed
pre_upload_gate.pynonejob state → compliance checklist validation, halts on failure
generate_metadata.pyClaude APIscript → metadata/<job-id>/metadata.json (title, description, tags, pinned comment)
upload_youtube.pyYouTube Data API v3video file + metadata → live upload with AI disclosure + pinned comment posted
monitor_upload.pynonejob id → prints monitoring reminder card (24h/48h/72h checklist)

Folder Structure

yt-shorts/
├── pipeline.py               ← run this for pre-edit
├── publish.py                ← run this for post-edit
├── tools/                    ← 12 tool scripts (above)
├── workflows/                ← markdown SOPs (one per tool)
├── topics/
│   └── queue.json            ← topic backlog, you edit status here
├── scripts/
│   └── <job-id>/
│       └── script.json
├── voiceover/
│   └── <job-id>/
│       └── voiceover.mp3
├── footage/
│   └── <job-id>/
│       ├── clip_01.mp4       ← audio-stripped
│       └── gaps/             ← drop Runway clips here
├── assets/
│   └── <job-id>/            ← open this folder in CapCut
│       ├── 01_clip.mp4
│       ├── voiceover.mp3
│       ├── script.txt        ← reference while editing
│       ├── overlays.txt      ← keyword list for text overlays
│       └── footage-gaps.md   ← Runway prompts (empty = no gaps)
├── output/
│   └── <job-id>/
│       └── final.mp4         ← your exported CapCut video goes here
├── metadata/
│   └── <job-id>/
│       └── metadata.json
├── compliance-logs/
│   └── <job-id>/
│       └── clearance.json
├── .tmp/
│   └── <job-id>/
│       └── state.json        ← checkpoint file for resume-on-failure
└── .env                      ← API keys
