Question 1 of 3: Topic Selection

The pipeline generates 10 scored topics at Step 2. How do you want to pick which one to produce that day?

A

Interactive terminal pick

Pipeline pauses after generation, prints the scored list in the terminal, you type a number (1–10) to select. Production continues immediately after your pick.

Best for: You want control over which topic runs today without touching any files.

B

Auto-select highest score

Pipeline picks the topic with the highest US curiosity gap score automatically. Fully hands-off — you never see the list.

Best for: You want to run the script and come back to a finished asset folder.

C

Queue-based (Recommended)

Topics are generated and saved to a Google Sheet / local queue. You browse, approve, and mark one as "ready" at your leisure. When you run the pipeline, it picks the first "ready" topic.

Best for: Building a backlog buffer so you're never scrambling for a topic. Aligns with the 30-day diversity rule — you can visually scan for topic repeats before approving.
