Question 3 of 3: Topic Queue Storage

You chose queue-based topic selection. Where should the queue live? This is where you'll browse, approve topics, and mark one "ready" before each pipeline run.

A

Google Sheets (Recommended)

Topics are written to a shared Google Sheet with columns: Title, Misconception, US Score, Status (pending / approved / used). You flip Status to "approved" from any device — phone, tablet, or desktop — before running the pipeline.

Best for: Reviewing and approving topics anywhere. You can also spot topic diversity violations visually. Aligns with your CLAUDE.md principle that deliverables live in cloud services.

B

Local JSON / CSV file

Topics are written to topics/queue.json. You edit the file locally to approve a topic before running the pipeline. Simple, no auth required.

Best for: Simplest setup. Works offline. Downside: you have to be at your desk to approve topics.

C

Both — local file synced to Google Sheets

Pipeline writes to local JSON as primary storage and mirrors the queue to Google Sheets for remote visibility. Approvals in Sheets are synced back on next pipeline run.

Best for: Resilience — works offline and remote. More complex setup, but no single point of failure.
