Question 2 of 3: AI Video Generation Gaps

Step 8 of your pipeline covers AI video generation when no stock footage exists. Kling / Runway / Pika don't have reliable public APIs yet. How should the pipeline handle footage gaps?

A

Gap report + manual generation (Recommended)

Pipeline automatically writes a footage-gaps.md file with the exact Kling / Runway prompts pre-written from your script. You open the tool, paste the prompt, download the clip, and drop it in the assets folder. Pipeline detects it and continues.

Best for: Reliability. AI video tools change APIs constantly — keeping this step manual avoids breakage. The prompt is already written so it takes under 2 minutes.

B

Placeholder flag — handle during editing

Pipeline marks missing clips as [GAP: prompt here] in the asset manifest. You decide during CapCut editing whether to generate AI video or substitute a different stock clip.

Best for: Fastest pipeline run. You make the call at edit time.

C

Kling API integration (beta)

Attempt automated Kling API calls for missing clips. The pipeline blocks until generation completes and downloads the result.

Best for: Fully automated. Risk: Kling's API is in beta, rate-limited, and costs credits unpredictably — one bad run can burn budget.
