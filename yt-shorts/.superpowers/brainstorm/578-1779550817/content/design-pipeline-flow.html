Design Section 1: Pipeline Flow

Two entry points. One job ID ties everything together across both runs.

Phase 1 — Pre-Edit  python pipeline.py

pipeline.py — orchestrates 8 tool scripts in sequence
Step Tool Script Output Checkpoint
1generate_topics.pyAppends 20 topics → topics/queue.json✅ state saved
⏸  You set status → "approved" in queue.json, then re-run pipeline.py
2generate_script.pyFull script + scores + footage queries → scripts/<job-id>/✅ state saved
3check_compliance.pyPASS or REVISION REQUIRED (auto-halts on fail)✅ state saved
4generate_voiceover.pyMP3 → voiceover/<job-id>/✅ state saved
5search_footage.pyDownloads clips → footage/<job-id>/ (Pexels + Pixabay, concurrent)✅ state saved
6clear_footage.pyStrips audio from every clip via ffmpeg, logs clearance✅ state saved
7check_footage_gaps.pyWrites assets/<job-id>/footage-gaps.md with Runway ML prompts✅ state saved
⏸  If gaps exist: go generate clips in Runway, drop .mp4 files into footage/<job-id>/gaps/, re-run pipeline.py
8package_assets.pyAssembles full asset bundle → assets/<job-id>/, prints edit checklist✅ DONE

Phase 2 — Post-Edit  python publish.py --job <job-id>

publish.py — orchestrates 4 tool scripts, requires exported video in output/ folder
Step Tool Script Output
1pre_upload_gate.pyValidates compliance checklist — halts if anything is unresolved
2generate_metadata.pyClaude API → title, description, tags → metadata/<job-id>/
3upload_youtube.pyYouTube Data API v3 → public upload with AI disclosure, posts pinned comment
4monitor_upload.pyPrints monitoring reminder card — 24h copyright, 48h monetization, 72h analytics

💡 Key improvements over your instruction.md

  • Job ID system — every run gets an ID (e.g. 20260523-snipers-laser) so all assets, script, voiceover, and metadata stay grouped and publish.py knows exactly which video to upload
  • Resume on failure — state.json checkpoint means a failed ElevenLabs call doesn't re-run Claude API (saves money)
  • Concurrent footage search — Pexels + Pixabay queried in parallel per sentence, cuts footage step from ~5 min to ~1 min
  • ffmpeg audio strip is automated — no manual step, every downloaded clip is cleaned before packaging
  • Runway gap report is pre-written — each gap entry includes the exact Runway prompt from your script, so you paste and go
  • Weekly topic batch mode — pipeline.py --topics-only generates 20 topics at once and queues them, so your daily run never starts cold
