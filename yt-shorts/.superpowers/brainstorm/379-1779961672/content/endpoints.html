YT Shorts — Full API Endpoint Map

All endpoints under /api/yt-shorts/. Per-item approval + commit pattern for multi-clip steps.

Method Endpoint Description Pattern
Core — Project Management
POST /api/yt-shorts/projects Create a new video project, returns project_id
GET /api/yt-shorts/projects List all projects with current step + status
GET /api/yt-shorts/projects/{id} Full project state — current step, all approved items
Step 1 — Topics
POST /api/yt-shorts/projects/{id}/topics/generate Generate 10 topic ideas via Claude regenerate
GET /api/yt-shorts/projects/{id}/topics List generated topics
POST /api/yt-shorts/projects/{id}/topics/{topic_id}/approve Select one topic, advance project to script step approval
Step 2 — Script
POST /api/yt-shorts/projects/{id}/script/generate Generate full script from approved topic regenerate
GET /api/yt-shorts/projects/{id}/script Get current script draft
POST /api/yt-shorts/projects/{id}/script/compliance Run compliance check — advertiser scores, flags
POST /api/yt-shorts/projects/{id}/script/approve Approve script, advance to voiceover approval
Step 3 — Voiceover
POST /api/yt-shorts/projects/{id}/voiceover/generate Generate voiceover via ElevenLabs regenerate
GET /api/yt-shorts/projects/{id}/voiceover Get audio file path + status
POST /api/yt-shorts/projects/{id}/voiceover/approve Approve voiceover, advance to footage search approval
Step 4 — Stock Footage
POST /api/yt-shorts/projects/{id}/footage/search Search Pexels + Pixabay per script sentence
GET /api/yt-shorts/projects/{id}/footage List all clips with approve/reject status
GET /api/yt-shorts/projects/{id}/footage/gaps Sentences with no matching stock footage
POST /api/yt-shorts/projects/{id}/footage/{clip_id}/approve Approve individual clip per-item
POST /api/yt-shorts/projects/{id}/footage/{clip_id}/reject Reject clip, triggers new search for that sentence per-item
POST /api/yt-shorts/projects/{id}/footage/commit Lock all approved clips, advance to AI footage step commit
Step 5 — AI Footage (gaps only)
POST /api/yt-shorts/projects/{id}/footage/ai/generate Generate AI clips for gap sentences
GET /api/yt-shorts/projects/{id}/footage/ai List AI-generated clips with status
POST /api/yt-shorts/projects/{id}/footage/ai/{clip_id}/approve Approve individual AI clip per-item
POST /api/yt-shorts/projects/{id}/footage/ai/{clip_id}/regenerate Regenerate just this one AI clip, no restart per-item
POST /api/yt-shorts/projects/{id}/footage/ai/commit Lock all approved AI clips, advance to music commit
Step 6 — Music
GET /api/yt-shorts/projects/{id}/music/options List available background tracks
POST /api/yt-shorts/projects/{id}/music/{track_id}/approve Select track, advance to asset packaging approval
Step 7 — Package Assets
POST /api/yt-shorts/projects/{id}/assets/package Bundle clips, voiceover, music into editor-ready folder
GET /api/yt-shorts/projects/{id}/assets Package status and output path
Step 8 — Pre-Upload Gate (after manual edit)
POST /api/yt-shorts/projects/{id}/gate/check Run all compliance checklist items
GET /api/yt-shorts/projects/{id}/gate Gate status — passed / failed items
POST /api/yt-shorts/projects/{id}/gate/approve Human sign-off, unlocks metadata + upload approval
Step 9 — Metadata
POST /api/yt-shorts/projects/{id}/metadata/generate Generate title, description, tags via Claude regenerate
GET /api/yt-shorts/projects/{id}/metadata Current metadata draft
POST /api/yt-shorts/projects/{id}/metadata/approve Approve metadata, unlock upload approval
Step 10 — Publish
POST /api/yt-shorts/projects/{id}/publish/upload Upload to YouTube with approved metadata
SSE /api/yt-shorts/projects/{id}/publish/stream Live upload progress events
GET /api/yt-shorts/projects/{id}/publish Upload status, YouTube video_id on success
Step 11 — Post-Upload Monitor
GET /api/yt-shorts/projects/{id}/monitor Copyright check (24h) + monetization check (48h)
POST /api/yt-shorts/projects/{id}/monitor/refresh Force re-check now
Step 12 — Analytics
GET /api/yt-shorts/projects/{id}/analytics Views, watch time, US% share, geo breakdown
POST /api/yt-shorts/projects/{id}/analytics/refresh Pull latest from YouTube Analytics API
Shared Core — all features
GET /api/core/jobs List all running/completed background jobs core
SSE /api/core/jobs/{job_id}/stream Live log stream for any background job core
SSE /api/core/events Global SSE feed — step complete, approval needed, errors core
