PHASE 2 AWS Production Stack

🌐
CloudFront + S3
React SPA served from S3 via CloudFront CDN · global edge delivery
🐳
ECS Fargate — API
Containerized Express API · auto-scales on CPU/memory · ALB in front
🐳
ECS Fargate — Workers
BullMQ workers in separate containers · scale text/image/video workers independently
🗃️
SQS (optional upgrade)
Replace BullMQ queues with SQS for AWS-native durability + dead-letter queues
🔴
ElastiCache (Redis)
Managed Redis cluster · same BullMQ code, different connection string
🗄️
RDS PostgreSQL
Multi-AZ for prod · automated backups · same schema, no migration needed
🔐
AWS Secrets Manager
Store AI provider API keys + Stripe keys securely · injected at runtime
💰 Estimated AWS cost: ~$80–150/mo at small scale · scales with usage
