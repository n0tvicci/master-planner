DB: credit_ledger (append-only log)

iduuid PK
workspace_idFK → Workspace
user_idFK → User (who triggered)
typepurchase | consumption | refund
amountinteger (+/-)
job_idFK → job (nullable)
stripe_payment_idnullable
created_attimestamp
Never update rows — only insert. Balance = SUM(amount) for workspace. Full audit trail.

Purchase + Consumption Flow

1
Owner/Admin selects a credit pack → Stripe Checkout session created server-side
2
Stripe redirects back → webhook fires checkout.session.completed → credits inserted into ledger
3
User submits a job → API checks balance atomically (DB transaction) → deducts credits + enqueues job in one operation
4
If job fails after deduction → refund entry inserted into ledger automatically
5
Credit balance displayed in real-time on dashboard — workspace-wide, visible to all members
⚠️ Atomic deduction rule: Credits are deducted and job enqueued in a single DB transaction. If either fails, both roll back. No double-spend, no free jobs.
